* Overview

=resumel= is an Emacs package for creating professional resumes and CVs using Org Mode and LaTeX templates. It currently supports four templates:

- *[[https://github.com/moderncv/moderncv][moderncv]]*: A classic, clean LaTeX template with multiple style and colour options.
- *[[https://github.com/liantze/AltaCV][altacv]]*: A modern two-column LaTeX template with a contemporary look.
- *[[https://github.com/posquit0/Awesome-CV][awesomecv]]*: A sleek, professional template with strong typographic hierarchy.
- *modaltacv*: A custom variant that combines the ModernCV aesthetic with the AltaCV two-column layout.

Designed for extensibility, resumel consolidates common macros and lets you swap templates with a single keyword.

* Features

- *Multiple Templates*: Choose from =moderncv=, =altacv=, =awesomecv=, or =modaltacv=.
- *Template Variable Introspection*: Browse, live-edit, and query all template configuration variables without touching the template source files.
- *Extensible*: Add new LaTeX templates by dropping an =.el= and =.org= file pair into a directory.
- *Unified Macros*: Consistent formatting (=cvtag=, =cvtags=, =wheelchart=, etc.) across all templates.
- *Automated Testing*: Visual PDF comparison tests for each template.
- *Emacs Integration*: Works with Vanilla Emacs, Doom Emacs, Spacemacs, and other distributions.

* How It Works

Write your resume in an Org file using template macros for sections like skills, experience, and education. =resumel-export= exports the file to PDF via LaTeX, applying the selected template. Templates are modular — each lives in its own directory with a =.el= file (LaTeX class definition) and a =.org= file (macros). Common macros are centralised in =resumel.org=.

* Prerequisites

- *Emacs* 26.1+  [[https://www.gnu.org/software/emacs/download.html][Download Emacs]]
- *LaTeX distribution*: [[https://www.tug.org/texlive/][TeX Live]] / [[https://miktex.org/][MiKTeX]] / [[http://www.tug.org/mactex/][MacTeX]]
- *diff-pdf*: required for running tests  [[https://github.com/vslavik/diff-pdf][diff-pdf GitHub]]

* Usage

** Quick Start

1. Select a template:

   #+begin_src
   M-x resumel-select-template RET moderncv RET
   #+end_src

   This writes =#+RESUMEL_TEMPLATE: moderncv= into the current Org buffer header so the selection is saved with the file.

2. Write your resume content using the provided macros (see fixture files in =tests/fixtures/= for examples).

3. Export to PDF:

   #+begin_src
   M-x resumel-export RET
   #+end_src

** Template Variables

Every template exposes a set of configuration variables that control fonts, colours, layout, and more. You can override any of them by adding a =#+RESUMEL_<VAR>: value= keyword to your Org file header. For example:

#+begin_src org
#+RESUMEL_TEMPLATE: moderncv
#+RESUMEL_MODERNCV_COLOR: green
#+RESUMEL_GEOMETRY: scale=0.8, top=1.5cm, bottom=1.5cm
#+end_src

*** Browsing variables

To see all available variables for your current template, their default values, and which ones you have overridden:

#+begin_src
M-x resumel-show-variables RET        (or resumel-show-all-variables)
M-x resumel-show-core-variables RET   (shared by all templates)
M-x resumel-show-template-variables RET  (template-specific only)
#+end_src

This opens a =*resumel: template variables*= buffer listing every variable on its own =#+RESUMEL_VAR: value= line.

*** Live editing

Variables can be edited *directly in the variables buffer* — changes sync immediately back to your Org file header. Press =g= to refresh the display and =q= to close.

*** Getting and setting individual variables

#+begin_src
M-x resumel-get-template-variable RET MODERNCV_COLOR RET
M-x resumel-set-template-variable RET MODERNCV_COLOR RET burgundy RET
#+end_src

=resumel-get-template-variable= returns the effective value: the buffer keyword if set, otherwise the template default.
=resumel-set-template-variable= inserts or updates the =#+RESUMEL_<VAR>:= keyword in your buffer header.

* Testing

#+begin_src shell
make test    # run all tests
make clean   # remove generated results
#+end_src

Tests export all fixture files and compare the resulting PDFs against expected outputs using =diff-pdf=.

* Adding New Templates

1. Create =templates/newname/= with =newname.el= (LaTeX class definition) and =newname.org= (macros).
2. In =newname.el=, define a =defconst resumel-newname-variable-defaults= alist listing every configuration variable and its default value.
3. Add ="newname"= to the =resumel-default-template= choices in =resumel.el=.
4. Add test fixture and expected PDF; run =make test=.
